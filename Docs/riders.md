# Riders

A rider is what happens to a target *besides* damage. When a save is rolled, a Strike lands, damage is
applied, or a turn ends, the conditions an item inflicts are applied to the right creature, on its own
sheet, without anyone clicking a condition on.

Riders are authored on whatever the rule belongs to — a spell, a feat, an action, an effect — under
`flags[<scope>].riders`, where `<scope>` is this module's id or any id registered with
`api.flags.registerFlagScope`:

```jsonc
"riders": [
    { "event": "strike-resolved",
      "outcomes": ["success", "criticalSuccess"],
      "predicate": [{ "or": ["item:category:unarmed", "item:trait:unarmed"] }],
      "apply": { "type": "save", "statistic": "will", "dc": "class", "riders": [
          { "outcomes": ["failure", "criticalFailure"],
            "predicate": [{ "not": "rider:target:condition:blinded" }],
            "apply": { "type": "condition", "slug": "blinded" } }
      ]}}
]
```

### Events

| `event` | Fires when | Whose riders are read |
| :-- | :-- | :-- |
| `save-rolled` *(default)* | A target rolls its save from a chat card | The item that forced the save |
| `strike-resolved` | This actor's Strike resolves | The attacker's items |
| `strike-received` | A Strike resolves against this actor | The defender's items |
| `action-used` | An action or spell is posted to chat | The item posted, against the targets you confirmed |
| `save-made` | This actor rolled a save against someone else's effect; the rider is aimed back at whoever forced it. `rider:trigger:enemy` / `rider:trigger:ally` say which side they are on (`rider:target:…` for an ordinary rider); every rider also sees the cast's choices as `rider:cast:<flag>:<value>` | This actor's items |
| `creature-dying` | A creature within the rider's `range` (feet) would die — a character at its dying maximum, anything else at 0 Hit Points — of anything but a death effect or *Disintegrate*. `trigger: true` reaches the dying creature; `rider:trigger:mode:living` says what it is | This actor's items |
| `damage-applied` | Damage from this actor's item lands | The origin's items |
| `damage-received` | Damage from someone else's item lands on this actor | The defender's items |
| `ally-damaged` | Damage lands on an **ally**, within the rider's own `range` in feet | The watching ally's items |
| `turn-start`, `turn-end` | This actor's turn begins or ends | This actor's items |
| `holder-acts` | This actor used an action or Cast a Spell. `rider:used:<type>` (`spell`, `action`, `feat`…) and `rider:used:trait:<trait>` say what was used — *Frozen Lungs*' "whenever it performs an auditory action or Casts a Spell" | This actor's items, and what they carry |
| `aura-tick` | A creature enters this actor's aura, or ends its turn inside it | The aura effect itself |

`ally-damaged` is the only event that takes a **`range`**, in feet. A rider without one never fires and
says so in the console: an ability that reaches the whole map is never what was meant.

A rider with no `event` means `save-rolled`. A rider with no `outcomes` fires on any outcome.

- **Only the item that produced the event is read** for `action-used`, `save-rolled` and `aura-tick`. The
  others search the whole sheet, because a Strike rider lives on the feat or armor rather than on the fist
  that threw it.
- **A roll the rider itself causes is not another use.** pf2e stamps the originating item onto every check
  it rolls, so the save a rider forces looks like the ability being used again. It is ignored.

### What a rider can do

The `apply.type` field. The built-in types are dispatched from one switch in `scripts/riders/apply.mjs`,
and `npm test` fails if this table and that switch disagree.

| `type` | What it does |
| :-- | :-- |
| `condition` | Applies a pf2e condition. `remove: true` takes one off; taking off *dying* raises *wounded*, as losing dying always does. `endsWith: [slug]` on a plain one ends it when that condition goes (*Vision of Death*'s fleeing). With a `duration` it becomes a generated effect that expires on its own; without one it is a plain condition for the table to clear. `max` caps a cumulative one. A `duration` with `of: "target"` ends on the **target's** turn ("until its next turn begins") rather than the caster's. `endsOnHostile` ends it once its holder uses a hostile action (an attack, a damage roll, or an action or spell aimed at an enemy). `withoutGrants` takes off conditions the condition would bring with it (*Sleep*'s unconscious without prone). `escapeDc` grants the captive an Escape action against that DC, and `escapeStatistic` names the one skill it is rolled with instead of the better of Acrobatics and Athletics. |
| `effect` | `preselect` answers a pf2e ChoiceSet: `"$outcome"` from the save, `"$cast"` from the spell's `castChoice`, `"$held"` the creature's one held weapon (*Runic Weapon*; with two or none, pf2e asks) (an object-valued choice by one of its values — *Enlarge*'s size); in `carries`, `"$cast:<flag>"` is the same choice. Applies an effect item by UUID — or one written out, with `label` and `rules` and no `uuid`. A written-out effect may carry a counter (`badge`), and an action its caster spends it with (`originAction`: `name`, `areaTargeting`, `riders` — fixed at the cast's DC and rank; *Blister*; `spends: false` for one that spends nothing, on a pf2e effect too — *Levitate*). `endsOnBlock: { immunity }` ends the effect when the shield it raised blocks, putting `immunity` (a pf2e effect) on in its place (*Shield*). `atCastRank` gives a pf2e effect the cast rank as its level, for effects whose rules read `@item.level` (*Heroism*). `preselect: { <flag>: <answer> }` answers a pf2e ChoiceSet before the effect lands (`"$outcome"` for the save's degree). `stack: true` walks a counter badge up instead of adding a second icon. `endsOnLeaving` ends it when the creature leaves the lingering area whose check gave it; `withArea` ends it when that area ends, wherever its holder is (*Hypnotize*). `escapeDc` grants an Escape, and `escapeAll` makes that Escape release everything the ability left. An effect or a timed condition can `carries` riders of its own, which fire on its holder's events; a save among them with no DC, or `"spell"`, is given the caster's DC when the effect is made. `link` remembers the creature the cast was aimed at, for the riders the effect carries. `forbids: [cast, attack, manipulate, concentrate, …any trait]` refuses its holder's casts, attack rolls and actions with those traits while it lasts (*Vapor Form*); `cooperative` refuses a ritual that needs secondary casters and a spell from a coven's entry (*Caster's Imposition*), and `forbidsExcept: { traits, slugs }` lets through what has one of those traits or slugs (*Moon Frenzy*: rage, Seek; *Silence*: a subtle cast), and the copy pf2e's Aura puts on a creature forbids the same; `addRules` adds rules to a pf2e effect; `originAction.holder` gives the action to the creature carrying the effect, and a `save` in its riders with no DC takes the spell's; `dismissable: "holder"` gives the Dismiss to the holder rather than the caster. `shield: { raise, hp, hpPerStep, immune, halvedAgainst }` makes a pf2e effect's shield a spell's own (*Fire Shield*): lowered until pf2e's *Raise a Shield* effect is on (`raise`), its Hit Points kept on the effect and taken down by each block — none by `immune` damage types — the effect ending at 0, and its Hardness halved against a blow with one of the `halvedAgainst` traits. `reveals: true` shows its holder through invisibility to every token that sees (a detection mode) and changes what an attack on it counts as concealed: only its invisibility, as concealment (*Revealing Light*). `untilPreparations: true` ends it when its caster Rests for the Night, wherever it is (*Darkvision* at 5th, *Light*, *Vital Beacon*); give it `duration: { unit: "unlimited" }`. `tether: true` counteracts, with the caster's spellcasting at the cast's rank, any teleport by a spell with the teleportation trait and any banishment of its holder, before it happens (*Planar Tether*). `unfettered: true` raises its holder's failed Escape checks — pf2e's and this module's — to successes, unless the hold is magical and of a higher rank than the cast (*Unfettered Movement*). `floor: { slug, value }` keeps its holder's condition of that slug at `value` or more while the caster can see the holder — a lowering clamped, a removal refused (*Evil Eye*). `nudge: { types }` raises a failed check of its holder's by one degree when one more point would (pf2e's own degree adjustment, so the card shows it), unless the check already has a status bonus, and then ends (*Nudge Fate*). `endsPrevious` with a `slug` ends the effects of that slug the same caster left on anyone (a previous casting). `shareDamage: { share, range }` splits its holder's damage with the caster (*Share Life*): each blow is altered to `share` before the holder's resistances apply, the rest goes to the caster untouched by theirs, and the effect ends when either is at 0 Hit Points or they move more than `range` feet apart. `noTurnHealing` takes away its holder's fast healing and regeneration while it lasts. `deters: { statistic, dc }` makes it a ward (*Sanctuary*): an attack on its holder first rolls the attacker's `statistic` (Will) against `dc` (the spell's, frozen when cast) — a critical success ends the ward, a success lets this turn's attacks through, a failure wastes this one and the rest this turn, a critical failure bars the attacker while it lasts. A written-out effect may name a `slug` for predicates to read (`target:effect:<slug>`). `sustained: { repeat: true }` also casts the spell again, at its rank and variant, each time it is Sustained (*Spiritual Armament*). `sustained: true` makes it last only while its caster Sustains the spell: the caster gets one *Sustain* action for it, and a turn ending unsustained (after the casting round) ends every effect the spell left. `sustain: { step }` gives the holder a *Sustain* action that adds `step` to the badge, once per round and not in the round it was cast. `heldFast: true` keeps the weapons in hand when it was made from being dropped, stowed or deleted while it lasts (*Metal Merged*). `flanksWith: true` makes its holder flank, with every other creature the cast reached, any enemy both stand adjacent to (*Pack Attack*). `dcSwap: { actions, dc, anchors }` raises the DC of a check by one of those `actions` against its holder to `dc` (`"spell"`, frozen at the cast) when that is higher; with `anchors`, someone else's push, pull or teleport of its holder must first counteract it (a spell) or beat that DC with Athletics (anything else), and a failed attempt — or a failed Shove or Reposition — whispers the holder a button that pushes the mover 5 feet away (*Bracing Tendrils*). `telepathy: true` gives its holder an action to speak to every other creature the cast reached (*Telepathic Bond*). `ventriloquism: true` gives its holder *Throw your voice*: its chat bubbles appear over a token it targets within 60 feet, and hearers may disbelieve — at 1st rank from a GM card, from 2nd on a Perception check of their own (*Ventriloquism*). `sharesSenses: true` lets its holder's players see through the targeted creature's token while its own sees nothing, with a Sustain action to switch back and forth (*Animal Vision*). `blindEye: { flag }` marks the item named in the cast's `flag`: scrying spells are refused while every pouch, focus or spellbook of its holder is marked, and a marked magical scrying item below twice the rank posts nothing (*Blind Eye*). `conjures: { flag }` puts an item named for the cast's `flag` in its holder's inventory, gone when the effect goes (*Creation*). `trail: true` leaves a Drawing at each of its holder's moves — hidden when the cast's `mode` is `invisible`, of the cast's `color` — each fading after a time set by the rank (*Glowing Trail*). `reminder: true` whispers the cast's `message` to its holder's owners once the cast's `days`, `hours` and `minutes` have passed on the world clock, then ends (*Timely Reminder*). `immuneTo: { flag }` wards its holder against the spell named in the cast's `flag` (`spell`): when that spell is cast with the holder among its targets, the warder counteracts it at the ward's rank, and on a success the holder is dropped from the targets (*Spell Immunity*). `glimpse` marks its holder: the first hit on it by the caster or an ally gives that striker pf2e's *Glimpse Weakness* at the cast's rank for its damage, and the mark goes (*Glimpse Weakness*). `airWalk` lets its holder change elevation as it walks, no more than the distance it covers (*Air Walk*). `trailFades: "duration"` keeps a `trail` for the effect's whole duration (*Breadcrumbs*). `endsOnHostileFrom` ends it when its caster or an ally uses a hostile action against its holder (*Bind Undead*); `endsOnHostileTo` when its holder uses one against the creature it is linked to (*Fated Healing*). `duplicates: { flag }` copies the caster's item the cast named into their hands, says the DC to tell it false, and ends when the copy's holder is more than 5 feet from the caster (*Blood Duplicate*). `namesPlace` puts where it was cast, and by whom, on its name (*Guiding Star*). `badge: "$cast:<flag>"` takes its counter from the cast's choice (*Magic Stone*). `onlyIfExpired` posts its `endNote` only when it ran its whole course, and `whileCondition` ends it when its holder loses that condition (*Dreaming Potential*). `endsWithArea: true` ends it when the area its spell left is gone, however it goes — made before the area, it is matched by the spell and caster (*Instant Parade*). `leash: { feet }` ends it when its holder stands more than `feet` from the other creature the cast reached (*Reflected Beauty*). `rune: { message, trigger }` posts the cast's message as a rune anyone can touch: the GM says whether the toucher meets the trigger, and the toucher hears it while the caster learns only that someone listened (*Message Rune*). `describes: <flag>` adds what the cast's field holds to the effect's name (*Glamorize*). `endNote` (a string key) is posted to its holder's players when the effect ends, however it ends, and `together` makes a Dismiss of one end every effect of the same caster's same spell (*Umbral Journey*). `enhanceSenses: true` reads its holder's senses as it lands: low-light vision, or darkvision over low-light vision already had, and every imprecise sense at twice its range (*Enhance Senses*). `draws: { feet }` marks an attack on its card when it falls under *Magnetize*: a ranged weapon attack at a creature within `feet` of the holder, or a melee Strike made from within `feet` at anyone else — pf2e does not record which weapons are metal, so the table settles it. |

| `victuals` | The food or drink the cast's `flag` names on the target — a loot pile, or the caster's own pack — or all its food: each poison in a pile is counteracted at the cast's rank against its level's DC, gone on a success; the food is renamed a fine version of itself, and back after an hour if it is still there. | `connections` | The nearest creature magically connected to the target — the caster of a sustained effect on it, others carrying an effect of the same caster's same spell, its familiar or master — less those named in the cast's `exclude` field: its distance and compass direction from the caster, never its name; off this scene, "on a different plane" when its scene's `plane` flag differs, else "beyond this map" (*Web of Influence*). |
| `recall` | Whispers the caster a card of `count` Recall Knowledge checks at no action: a skill to pick (the Recall Knowledge skills and every Lore) and a button that rolls it secretly. Those checks drop every roll note that answers a Recall Knowledge (*Hypercognition*). |
| `journey` | Whispers the caster the group's pace: pf2e's 8 miles a day per 10 feet of the slowest traveller's Speed, `days` of it each hour, over `hours`. Give it `self: true` (*Umbral Journey*). |
| `adjust` | On the action an effect's `originAction` grants: asks what changes now and writes it on the effect's name (*Glamorize*'s Sustain). |

| `pathway` | The caster, on or beside a fire or tree on the board (a Region, Tile or Drawing named with `feature`), is whispered every other one in reach — on this scene by feet and compass, on another by the miles between the scenes' `at` flags — and steps out at the one they click, or back where they went in. `miles` gives the reach by rank (`"planet"`: any scene on the same `plane`); an extradimensional item carried fails it (*Fire's Pathway*, *Nature's Pathway*). |

The watcher's attacks on that creature need its DC 11 flat check first (a failure loses the attack), and that creature's attacks find the watcher off-guard. `onlyEffectOrigin`: only when `hidden` gave the effect carrying the rider (*Blinding Fury*). |
| `cast` | Casts the rider's own spell at the rider's creature — a reaction that is a spell (*Schadenfreude*, nested with `trigger: true`). |
| `aftermath` | On the cast (`self: true`): a tally of the creatures it reached and of those that must answer (`awaits`, a predicate). `aftermath-mark` — the last of each answering creature's riders — ticks one off and notes whether it died. When none is left: with nobody dead, `none` lands on every reached creature `noneTo` admits, `noneSelf` on the caster (*Massacre*'s backlash). Kept on the active GM's client. |
| `aftermath-mark` | The last of each answering creature's riders under an `aftermath`: this one's result is in. |
| `affliction` | Afflicts the creature — an effect whose badge is the stage and whose rules grant the stage's conditions (pf2e's own affliction item exists only in its development builds): `name`, `stage` (where it starts), `stages` (`damage: [{ formula, type }]`, `conditions: [{ slug, value }]`, `duration`), `maxRounds`, `save` — the DC is the spell's. Each stage's damage is rolled and applied as it begins; at the end of each of the creature's turns it saves (critical success −2 stages, success −1, failure +1, critical failure +2), ending below stage 1 or after `maxRounds`. Exposed again, it moves up by `stage` (*Spider Sting*). |
| `spend-charge` | The action an effect with `originAction` grants its caster spends one of the effect's counter badge; the last one ends the effect, and the action goes with it. Its `areaTargeting` may say `includesOrigin`: the creature the area is aimed from is caught with it. Not written by hand. |
| `dismiss` | The *Dismiss* action an area with `dismiss` — or an effect with `dismissable` (*Animal Form*) — grants its caster; not written by hand. Using it deletes the area or the effect. |
| `area-damage` | Damage rolled **once for the cast** and saved against once per creature (`save`, basic): each of `parts` (`formula`, `perStep`, `type` or `typeFromSpell`: one of the spell's own damage partials) is rolled once; a part with a `zone` reaches only the creatures the placement named for that zone (`areaTargeting.zones`); what reaches a creature lands as one roll of several types (*Falling Stars*). A part with `weaponDice` (and `perStepDice`) rolls that many dice of a weapon the caster holds, its die as held and its type; `critSpecialization` puts the weapon's critical specialization effect on a critical failure (*Weapon Storm*). Its `riders` follow the creature's save by `outcomes` (*Blazing Fissure*'s prone). |
| `pull` | Every creature the cast reached saves (`save`), then each moves toward the area's centre by `feet[outcome]`, nearest first, a square at a time, stopping at walls, other creatures and the centre — forced movement, no reactions (*Gravity Well*). Needs `areaTargeting.markCentre`. |
| `contest` | The caster rolls `statistic` (`"spell-attack"`: the spell's own) against the target's `against` DC; the nested `riders` are chosen by the caster's result (*Telekinetic Maneuver*). A nested rider with `toOrigin` lands on the caster. |
| `disarm` | The target's held weapon: `mode: "loosen"` is pf2e's *Effect: Disarm (Success)* on that weapon (–2 to its attacks while held), `"drop"` lets go of it. |
| `rays` | One spell attack per targeted creature, all at the penalty the cast chose; a hit rolls the cast's own damage and applies it, doubled on a critical hit (*Blazing Bolt*). Put it on `self: true`: it runs once, with every target. `failure: [types]`: what a miss still deals (*Live Wire*); `riders`: by the ray's result, on the creature it reached. `save: { statistic, worseOnCritical }`: a hit is a basic save against the spell DC instead, one degree worse on a critical hit; `objects: "destroy"`: a hit on a wall section or a hazard destroys it (*Disintegrate*). |
| `climb` | Moves a valued condition by `by` (negative to lower it) within `[0, max]`; reaching `max` runs the riders in `onMax`, reaching 0 those in `onZero` — *Petrify*'s slowed that turns to stone. |
| `shorten` | Takes `rounds` off the effect that carries this rider, or ends it with `rounds: "all"` — *Paralyze*'s save at the end of each turn. |
| `strikes` | Rolls a volley, dealt round-robin across the confirmed targets. `mapIndex` picks the variant. Follows through to damage. |
| `toggle` | Flips a roll option on the **target**, unless the rider is `self`. |
| `reaction` | Offers the actor a reaction, as buttons on a card. |
| `prompt` | Whispers the GM. Automating half of a rider and being honest about the other half beats guessing. |
| `pick` | Whispers the caster a card of **creatures** — everything within `range` feet matching `affects` — and applies the nested `riders` to the one they click. |
| `choice` | Whispers the caster a card of buttons and applies the one they pick. |
| `detect-magic` | On the cast (`self: true`): the magic within `range` feet — creatures' magic items, the effects spells and magic left on them, spells' areas on the ground — whispered to the caster: present or not; from 3rd rank the highest rank or level, from 4th where it is. An illusion counts only below the spell's rank; `ignoreKnown` leaves out the caster's and their allies' own (*Detect Magic*). |
| `readout` | Posts an informational card and touches no sheet. |

Another module adds its own with `api.riderExtensions.registerApplyType(type, fn)`; the built-in types
cannot be replaced.

**The DC.** A `save` rider's `dc` is a number, or a word a registered DC resolver answers
(`registerDcResolver`). With no `dc` at all it is the origin's class DC, else its best spell DC. A
`counteract` with no `statistic` uses a registered default, else the origin's class DC statistic, else its
best spellcasting.

**A rider is not only a thing done to a target.** `heal`, `toggle` and `strikes` act on the origin when the
rider is `self`; `prompt`, `choice`, `pick` and `readout` produce chat output without touching a sheet.

### Areas

A `turn-start` or `turn-end` rider can carry an `area`, and then it fans out from the origin's token
instead of landing on one creature. It reuses the containment and alliance filtering of cast-time area
targeting, so "enemies within 10 feet" means the same thing in both places. `area.anchor` centres it on a
named point another module provides (`registerAreaAnchors`).

### Asking about the target

Predicates can use the system's own `target:*` options, plus a `rider:*` vocabulary for the questions an
escalating rider needs to ask:

| Option | True when |
| :-- | :-- |
| `rider:target:condition:<slug>` | The target has that condition |
| `rider:target:condition:<slug>:<n>` / `:<n>+` | …at exactly, or at least, that value |
| `rider:target:effect:<slug>` | The target carries that effect |
| `rider:target:effect:<slug>:<n>` / `:<n>+` | …with a counter badge at exactly, or at least, that |
| `rider:target:hp-zero`, `rider:target:hp-half-or-less` | Health, after the damage landed |
| `rider:damage:type:<type>` | The damage that fired this rider included that type |
| `rider:damage:outcome:<outcome>` | The Strike that dealt it had that degree of success |
| `rider:damage:blocked` | `damage-received`: its holder Shield Blocked it, with a raised shield |
| `rider:damage:melee`, `rider:damage:unarmed` | …it came from a melee attack, an unarmed one |
| `rider:damage:adjacent` | …from an attacker within 5 feet |

Every predicate is tested against a snapshot taken **before** anything is applied, so an escalation
ladder advances exactly one step per hit. A `live` rider is tested against the world as the pass leaves it.

Rerolls are handled: changing the degree of success removes the riders applied for the old one and applies
the new set, and only ever removes what this module created — including winding a counter badge back down.

This needs a **GM online**, because a player cannot write to a monster's sheet. If none is, the caster is
told what would have been applied. Turn the whole thing off with **Apply riders automatically**.

### With pf2e-toolbelt

Pairs with [`pf2e-toolbelt`](https://github.com/reonZ/pf2e-toolbelt)'s **Target Helper**. Targets set by
area targeting arrive on the chat card as its per-target rows, each rolls its own save from the card, and
each of those rolls is what `save-rolled` riders key off.
